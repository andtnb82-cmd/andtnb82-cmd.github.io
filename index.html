gptapiozon

Проверка доступа на чтение проекта Google Apps Script для владельца аккаунта andtnb82-cmd. Авторизация через Google позволяет выполнять проверку в GitHub Actions без повторного ручного входа в браузер, пока предоставленное разрешение и токены действуют.

Текущая версия — только чтение. Инструмент не изменяет код, не выполняет функции Apps Script и не запускает загрузку данных Ozon.

Как работает инструмент

  1. Владелец выбирает скачанный Desktop OAuth JSON в локальной программе и подтверждает доступ на странице Google.
  2. Разрешение ограничено чтением проектов Apps Script: script.projects.readonly.
  3. Владелец переносит данные авторизации в GitHub Actions Secrets закрытого рабочего репозитория.
  4. Проверка читает один настроенный проект и выводит статус, список файлов, размеры и контрольные суммы. Исходный текст и токены в журнал не публикуются.

Данные под контролем владельца

Этот сайт служит только описанием приложения. Он не принимает учётные данные и не содержит формы входа. Полученные через Google API данные не используются для рекламы или обучения моделей ИИ. Подробности обработки, хранения и отзыва доступа приведены в политике конфиденциальности.

Использование и поддержка

Проект предназначен для личного использования владельцем, бесплатно. Условия использования описывают назначение инструмента и ограничения доступности.
