Как обрабатываются данные

Эта политика описывает текущую версию личного инструмента gptapiozon: локальную авторизацию Google и проверку доступа на чтение проекта Google Apps Script через GitHub Actions. Оператор — владелец аккаунта GitHub andtnb82-cmd.

Какие данные доступны приложению

Приложение запрашивает только разрешение https://www.googleapis.com/auth/script.projects.readonly. Оно позволяет читать проекты Apps Script, доступные авторизованному пользователю. Проверка обращается к одному настроенному проекту и получает его файлы: имена, типы и исходный текст. Это разрешение не предоставляет изменение кода или выполнение функций.

Для OAuth используются идентификатор клиента, секрет клиента, одноразовый код авторизации, access token и refresh token. Пароль Google приложение не получает. Доступ к Gmail, контактам или содержимому Google Sheets в этой версии не запрашивается.

Зачем используются данные

Данные используются исключительно для проверки доступа и определения состава и контрольных сумм файлов настроенного проекта. Google user data не используются для рекламы, продажи данных или обучения моделей искусственного интеллекта.

Где обрабатываются и хранятся данные

Локальная программа читает выбранный пользователем OAuth JSON. Этот скачанный файл остаётся на его компьютере, пока пользователь сам его не удалит. Полученные токены локальная программа держит в памяти и не записывает в файлы. По команде пользователя отдельное значение помещается в системный буфер обмена. Программа пытается удалить своё значение через 45 секунд или при закрытии, если оно не было заменено другим текстом. История и синхронизация буфера операционной системы управляются отдельно пользователем.

Пользователь вручную сохраняет три значения в GitHub Actions Secrets своего закрытого рабочего репозитория. При проверке GitHub Actions обменивает refresh token на access token у Google, затем читает проект Apps Script. Исходный код обрабатывается в памяти процесса; текущая проверка не публикует и не сохраняет его в артефактах. В журнал выводятся идентификатор проекта, имена и типы файлов, размеры и SHA-256, а также обезличенные коды ошибок. Токены и секреты не выводятся.

Поставщики услуг и сроки хранения

Google обрабатывает запросы авторизации и API; GitHub хранит Secrets и журналы выполнения и предоставляет среду GitHub Actions. Эти данные передаются поставщикам только для работы описанного механизма. Secrets хранятся до удаления или замены владельцем. Срок хранения журналов определяется настройками GitHub Actions; владелец может удалить их раньше. Посторонним получателям данные намеренно не передаются.

Доступ к данным Google ограничен указанными целями. Использование и передача информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа и удаление

Отозвать разрешение можно в подключениях аккаунта Google. Для удаления сохранённых данных нужно удалить соответствующие Secrets и журналы GitHub Actions, закрыть локальную программу и при необходимости удалить OAuth JSON и историю буфера обмена на компьютере. Контакт для вопросов об удалении данных будет добавлен перед публикацией.
